# Assets do marketplace

Os arquivos `emerald-ape.webp`, `sage-nomad.webp`, `neon-vessel.webp`, `golden-beat.webp` e `golden-signal.webp` são ilustrações geradas para esta demonstração, usando a captura fornecida pelo usuário como referência de personagens e estilo. Não são exportações dos assets originais do Figma. A exportação pelo conector foi recusada por falta de acesso ao arquivo.

As imagens foram convertidas para WebP com 768 × 768 px e qualidade 88. Os cinco arquivos somam aproximadamente 440 KB. A home reutiliza as mesmas imagens no destaque, nos cards e no banner lateral; os nomes e os caminhos vêm das fixtures MSW.

Os SVGs `nft-*.svg` da primeira versão foram preservados porque recibos antigos podem referenciá-los. Quando os assets originais autorizados estiverem disponíveis, substitua os cinco WebPs mantendo os caminhos, ou atualize os caminhos correspondentes em `src/mocks/fixtures.ts`.
